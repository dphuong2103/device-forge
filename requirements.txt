### Core Concept
- Users install a lightweight **Agent** on their Windows computer.
- The Agent creates and manages virtual Android devices on the user’s own machine.
- Users interact with a modern web interface that runs locally (localhost).
- Our cloud only handles accounts, subscriptions, and license validation.
- The product is designed for developers and QA teams to test Android applications across different device configurations.

### Key Features the system must support
- Create and manage multiple virtual Android devices locally
- Live screen streaming + touch/keyboard input in the browser
- **Main Device** concept + multi-device actions (apply changes to Main Device and/or selected devices)
- One-click **Randomize Device Identity** (realistic profiles for testing)
- Set / change **Proxy** (HTTP & SOCKS5)
- Set / change **GPS Location**
- **Full Device State Snapshot & Restore** (identity + apps + app data + settings)
- Bulk actions
- Subscription / license system

### Technical Preferences
- Frontend: Next.js (App Router) + TypeScript (runs on localhost)
- Agent Backend: Go (preferred) or another high-performance language
- Real-time: WebSocket
- Communication: Frontend ↔ Local Agent via localhost API + WebSocket
- Agent connects outbound to our cloud only for authentication and subscription checks
